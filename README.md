# Platrack

**Your path to Platinum.**

Platrack é uma startup acadêmica desenvolvida para a disciplina de **Security Governance, Risk & Compliance**.

O conceito inicial é um companion app mobile focado em jogadores de PlayStation que querem conquistar a platina, mas têm dificuldade para acompanhar troféus perdíveis, coletáveis e objetivos que passam despercebidos durante a campanha.

## Produto

Principais conceitos do MVP:

- PlatPath — rota personalizada até a platina
- Missable Alerts — avisos de objetivos que podem ser perdidos
- Collectible Tracker — acompanhamento de coletáveis
- Spoiler Safe — orientação sem entregar pontos importantes da história
- Dashboard de progresso — troféus, tempo estimado e progresso geral

## Stack atual

A landing page atual é estática:

- HTML
- CSS
- JavaScript

Sem backend e sem integração real com PlayStation nesta fase.
